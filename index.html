Projekt 1: CozyFocus (grupprojekt i kursen Interaktionsprogrammering)

CozyFocus är en webbaserad studie- och produktivitetsapp som hjälper studenter att planera studier, hantera uppgifter och hitta studiemiljöer i närheten.

Min roll i projektet:

  • Implementerade autentisering med Firebase (inloggning med e-post/lösenord och Google)
  • Byggde persistenslagret med Firestore för användarspecifik data (uppgifter, studieplaner, app-state)
  • Kopplade applikationsmodellen till databasen så att data sparas och laddas korrekt per användare
  • Ansvarade för inloggningsflöden och sessionshantering i applikationen

Vad jag lärde mig:

  • Designa persistens för användarspecifik data i en webbapplikation
  • Hantera autentisering och inloggningsflöden på ett säkert sätt
  • Integrera backend-tjänster (Firebase) med frontend (React)
  • Samarbeta i team med Git och uppdelade ansvarsområden

Kodexempel: Firebase Authentication

Kod som jag implementerade för autentisering i CozyFocus. Den hanterar registrering, inloggning med e-post/lösenord, Google-inloggning samt utloggning genom Firebase Authentication.

Kodexempel: Firestore Persistence Layer

Kod som jag implementerade för att koppla applikationsmodellen till Firestore. Funktionerna ansvarar för att spara och läsa användarspecifik data så att varje användare får sina egna uppgifter, studieplaner och inställningar.

Projekt 2: THS Business – Webbplattform (pågående)

Jag är med och utvecklar en webbplats för THS Business (en del av studentföreningen THS). Målet är att göra det enkelt för PR- och Event-teamet att publicera nya event och produkter som företag kan köpa, samt att låta företag publicera jobbannonser som studenter kan söka direkt via sidan.

Min roll i projektet:

  • Bidrar löpande med utveckling av frontend (HTML, JavaScript, TypeScript)
  • Bygger och förbättrar UI-komponenter och sidlayout (”dekorativt”/presentation)
  • Implementerar kopplingen mot Contentful så att innehåll kan uppdateras av teamen utan att gå via utvecklarna

Tekniker:

  • HTML, JavaScript, TypeScript
  • Contentful (headless CMS) som backend för innehåll
  • Teamarbete med regelbundna möten och gemensam planering

Vad jag lär mig:

  • Att utveckla en produkt i team med kontinuerliga leveranser
  • Att bygga användarvänligt innehållsflöde via headless CMS (Contentful)
  • Att strukturera frontend-kod för en växande webbapplikation
